Claude Opus 5.5가 사용자의 직접 제작 요청으로 작성한 실제 장면·필터 코드와 설계 응답입니다. 게임, 무대, 필터로 나누어 제작한 뒤 앱에 통합했습니다. 설계 목표와 검증 결과는 [사용 문서](frontrecord.md)에서 구분합니다.

## 게임 재구성

## 프리즘 활주 / 잉크 결투

**Racing**: 박스 차량, 가드레일, 큐브 건물을 모두 없앴습니다. 새 기체는 타원 동체, 유리 캐노피, 양쪽 원통 포드, 얇은 리어윙으로 된 유선형 hover racer입니다.
- 노면: 64행 리본 버퍼를 build 때 한 번만 할당하고, 매 프레임 실제 파형 높이와 drift 곡률로 정점만 갱신합니다.
- 서스펜션: 저음 스프링으로 차체가 눌립니다.
- 이동: 도로 이동 거리는 energy를 적분해서만 늘어납니다.
- 부스터: onset이 들어오면 interval 길이의 envelope로 화염이 늘어납니다.
- drift: centroid, waveBalance, 파형 좌우 비대칭으로 drift 각도를 정합니다.
- 측면 광주: 인스턴스 1회 draw로 그리며, 높이는 원시 band×gain입니다.

**Fighting**: 동물 리그를 폐기하고 관절 인체 2기를 새로 만들었습니다(골반, 척추, 어깨, 팔꿈치, 고관절, 무릎, 주먹).
- 공격 촉발: onsetLeft/Right의 상승 에지만 공격을 일으키고, 지속 시간은 f.interval입니다. 같은 소리가 계속되면 재무장되지 않아 추가 공격이 없습니다.
- 공격 각도: 저역/고역 우세, centroid(높이), roughness(hook), waveBalance(손 방향), bass/high(킥)로 정해집니다.
- 반동: 공격하지 않는 쪽은 상대 envelope만큼 뒤로 물러납니다.
- live=false이거나 정지 상태면 모든 목표가 0이 되어 중립 자세로 보간만 합니다.

## 무대 재구성

## FrontRecord 새 미술방향: Prism Ballet / Moonlit Chamber

**Dance**: 다면체 머리와 회전 헤일로를 가진 발광 관절 인형입니다. 척추, 목, 어깨, 팔꿈치, 고관절, 무릎이 모두 실제 파형(wavePoint)과 FFT 대역, onset에 직접 반응합니다. 두 손이 그리는 체인 궤적은 사용자 3색 그라데이션으로 칠해집니다. 화면 전체를 가로지르는 32점 파형 아크는 대역 크기에 맞춰 커지고, onset의 상승 순간에만 파편 스파크가 튑니다.

**Orchestra**: 반원으로 열린 배치에 다섯 동물이 섭니다.
- 올빼미: 지휘봉
- 개구리: 바이올린
- 사슴: 첼로
- 사자: 트럼펫과 밸브 3개
- 펭귄: 피아노와 건반 5개

공통 연미복 실루엣에 종마다 다른 머리 형태(귀깃, 눈혹, 뿔, 갈기, 부리)를 붙였습니다. 활, 지휘봉, 밸브, 건반은 대역 값과 signed wave에 직접 연결됩니다.

**제약 준수**: 메시는 장면당 약 95개이고 텍스처와 그림자는 없습니다. 재질과 geometry는 build 시점에만 만듭니다. live나 moving이 꺼지면 기본 자세로 보간만 합니다.

## 디더링 · 픽셀 표시

## SceneFilter 설계
- **0 원본**: `renderer.render`를 직접 호출하고 render target 비용이 없습니다. 0으로 전환하면 GPU 타겟을 해제합니다.
- **1 디더링**: 네이티브 크기 RT에 렌더한 뒤 4x4 Bayer 임계값(mod 연산)으로 6단계 양자화합니다.
- **2 픽셀**: 약 6px 셀 크기의 저해상도 RT를 NearestFilter로 업스케일합니다.
- **3 픽셀+디더링**: 셀 비율에 맞춘 `gl_FragCoord`로 고정 패턴을 적용합니다.
- RT는 선형으로 저장하고, 최종 1pass에서 톤매핑과 sRGB 변환을 한 번만 수행한 뒤 양자화합니다. 검은색은 0으로 유지됩니다.
- 이전 타겟과 viewport를 복원합니다. 프레임 루프에서는 객체를 할당하지 않으며, 오류는 throw로 호출부 fallback에 맡깁니다.
