# 일회성 조사 스크립트

첫 번째 기기를 진단·백업·설정할 때 사용한 원본 스크립트의 공개용 사본입니다. 개인 경로와 기기 일련번호·네트워크 주소를 치환했습니다. 원시 입력 자료, 전체 백업, 제조사 펌웨어와 외부 도구는 포함하지 않습니다.

이 스크립트는 당시 작업 폴더의 특정 파일 배치와 한 기기의 검증 결과에 의존합니다. 새로운 기기에 그대로 실행하지 마세요. 특히 EDL 쓰기 파일의 고정 주소는 당시 기기의 기록일 뿐 재사용 값이 아닙니다. 새 기기는 실제 GPT와 별도 백업으로 확인하고 `tools/`의 기기별 검증 절차를 사용합니다.

실험 코드도 포함하며 공식 YouTube 정상 재생 및 Google 환경의 영구 통합을 보장하지 않습니다. 현재 확정 결과는 `docs/first-device.md`를 참고하세요.
